## 1. 対象

Settingsの「データコントロール」にある、データを収集して学習へ利用する機能を将来実装する際の予約事項とする。

## 2. 全Modelでの共有

収集したデータは、特定のModelやProviderだけに閉じたものにせず、Platformで扱う全Modelが共有・使用できる構造および設計とする。

## 3. Privacy要件

ユーザー入力からデータを収集する場合は、Privacy、個人情報、機密情報、同意、利用範囲などを相当に注意して扱う。

ChatGPTに見られるようなデータの断片化を含め、収集・保存・共有・学習利用に必要となるPrivacy保護策を一通り組み込む方向で検討する。

## 4. 現時点の境界

本書は将来作業の予約記録であり、具体的な収集方式、断片化方式、保存形式、共有境界、同意・削除・保持の詳細設計は実施時に定義する。
